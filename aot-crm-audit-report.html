1. Executive Summary

AOT CRM is a Next.js 16 (App Router, React 19, TypeScript strict) enterprise CRM. Authentication is Microsoft Entra ID (next-auth v5 beta).

All CRM data now persists to PostgreSQL through Prisma 7.9.1 with the @prisma/adapter-pg driver adapter (Supabase PostgreSQL). Files/attachments persist to Supabase Storage (bucket crm-documents) via the Storage REST API.

Every CRUD module reads/writes the database. All mock repositories, hardcoded data.ts fixtures, and static module seed arrays have been removed from application code. The in-memory MockRepository survives only as a test fixture under tests/fixtures/.

Data survives restart/redeploy. Page refresh, server restart, and redeployment no longer reset CRM data.

Verification: npx tsc --noEmit clean • npm run build succeeds (all 58 routes compile).
