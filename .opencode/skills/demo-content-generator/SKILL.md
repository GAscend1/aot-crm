## What I do

Create safe synthetic product demo content for the CRM and public website.

## Architecture rules

- Generate fictional companies with realistic industry, size, location
- Generate fictional contacts with roles, emails, phone numbers
- Generate fictional leads with source, status, score
- Generate fictional opportunities with stage, amount, probability
- Generate fictional meetings with attendees, agenda, notes
- Generate fictional emails with threading, attachments
- Generate fictional reports and dashboards
- Generate fictional activity timelines
- Screenshot-ready dashboards with realistic-looking data
- Video demonstration scripts for product walkthroughs
- Onboarding demo content for new user training
- All synthetic data must be clearly marked as demo/synthetic

## When to use me

Trigger this for:
- demo environment setup
- public website demo data
- screenshot preparation
- video script creation
- onboarding content
- training data generation

## Prohibited

- Real customer data of any kind
- Real employee data
- Real credentials or tokens
- Production documents or files
- Private company information

## Validation

- Verify all generated data is clearly synthetic/fictional
- Confirm no real personal information is included
- Check demo data matches the expected schema
- Ensure demo content is properly isolated from production
