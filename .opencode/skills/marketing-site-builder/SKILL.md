## What I do

Build the public AOT CRM SaaS website.

## Architecture rules

- Pages: Home, Features, Solutions, Integrations, Pricing, Security, Resources, Login, Register, Book a Demo
- Original AOT copy and visuals — no competitor asset copying
- Reusable marketing components in `components/marketing/`
- SEO metadata via `next/head` or Next.js metadata API
- Open Graph metadata for social sharing
- Structured data (JSON-LD) for search engines
- Sitemap generation
- Responsive design at all breakpoints
- Accessible media controls for video/audio
- Lazy-loaded images and videos
- Optimized WebP/AVIF images
- MP4/WebM product demo support
- Synthetic CRM data only — no real customer data
- Product screenshots and video placeholders
- Restrained motion with reduced-motion support

## When to use me

Trigger this for:
- public website pages
- marketing content
- SEO optimization
- landing pages
- pricing page
- demo booking

## Prohibited

- Copying competitor website assets or copy
- Using real customer data or product data
- Missing SEO metadata
- Unoptimized images (always use next/image)

## Validation

- Verify SEO metadata on every page
- Check Open Graph tags render correctly
- Confirm structured data is valid JSON-LD
- Check image optimization (next/image, WebP/AVIF)
- Verify responsive layout at all breakpoints
- Confirm reduced-motion support
